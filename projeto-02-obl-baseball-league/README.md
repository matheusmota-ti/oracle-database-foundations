# 📊 Projeto de Banco de Dados da Cafeteria — Projeto de Banco de Dados

Projeto de modelagem de banco de dados desenvolvido a partir do enunciado e dos requisitos do estudo de caso **Oracle Coffee Shop**, como parte do curso **Database Foundations** da **Oracle Academy**.

---

## 🎯 Objetivo

O objetivo deste projeto é analisar as regras de negócio fornecidas, projetar o modelo conceitual/lógico de dados e implementar a estrutura física correspondente no banco de dados.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Oracle SQL Developer Data Modeler:** Para a construção do Diagrama de Entidade e Relacionamento (DER).
- **Oracle SQL / Oracle Database:** Para o desenvolvimento das consultas e dos scripts DDL e DML.
- **Git & GitHub:** Para versionamento e documentação do projeto.

---

## 📌 Etapas do Desenvolvido

1. **Levantamento de Requisitos e Entidades:** Identificação das principais entidades do sistema e das suas propriedades.
2. **Modelagem Conceitual e Lógica:** Definição dos atributos, chaves primárias (PKs) e chaves estrangeiras (FKs), bem como os relacionamentos e cardinalidades.
3. **Mapeamento Físico:** Geração do esquema relacional de tabelas.
4. **Construção de Scripts SQL:** Criação dos arquivos para definição de tabelas, inserção de dados de teste e execução de consultas de verificação.
